HTTP Server Pro runs a genuine nginx engine on your Android phone — no root, no computer — and can give your site a public HTTPS link in one tap.

HTTP Server Pro

AndroidComing to Google Play

Everything you need to host, share and build — running entirely on the phone.

  • Real nginx engine. Virtual hosts, routes, live logs and a full config editor.
  • Public HTTPS link. One tap opens a secure tunnel that works on any network.
  • Cloud Share. Send and receive files with anyone by link, with a live visitor monitor.
  • AI website builder. Describe a site and it writes the files — with your own Gemini key.
