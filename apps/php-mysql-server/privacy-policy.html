Privacy Policy

App: Php Mysql Server (com.php.myql.server) · Effective date: 13 October 2026

Php Mysql Server ("the app") lets you run a local PHP web server and a MySQL-compatible (MariaDB) database on your own Android device. This policy explains what information the app handles. In short: the app does not collect, sell or share your personal data, and it contains no ads, analytics or tracking.

1. Information we collect

We do not collect any information. The developer has no servers that receive data from the app, and the app has no user accounts, sign-in, advertising SDKs, analytics SDKs or crash-reporting SDKs.

2. Data stored on your device

Everything you create with the app (web project files, databases, settings, logs and backups) is stored locally in the app's private storage on your device. It never leaves your device unless you choose to expose it (see sections 3 and 4). Uninstalling the app deletes this data. You can export your project files through the Android Files app and create database backups inside the app.

3. Local network access

By default the servers listen only on the device itself (127.0.0.1). If you switch on "Expose to network" in the app settings, other devices on the same Wi-Fi network can reach your PHP server and database port. You are responsible for choosing a root password and for the content you serve.

4. Optional public URL (Cloudflare Tunnel)

The app can optionally create a temporary public web address using Cloudflare's free "Quick Tunnel" service (trycloudflare.com). When you enable this feature, the app connects to Cloudflare, and internet traffic to that address is relayed through Cloudflare to the web server running on your device. This means that:

  • anyone who knows the generated URL can open the website you are serving;
  • Cloudflare processes the traffic that passes through its network according to Cloudflare's Privacy Policy;
  • the developer of this app does not receive, see or store that traffic.

The tunnel is off unless you turn it on, and it stops when you stop the PHP server or tap "Close tunnel". phpMyAdmin is automatically protected by a login while the tunnel or network exposure is active.

5. Permissions used

  • Internet / network state / Wi-Fi state – to run the local servers, show your LAN address and (optionally) open the Cloudflare tunnel.
  • Foreground service – to keep the servers running while the app is in the background; a notification is shown while they run.
  • Notifications – to show that status notification.
  • Wake lock – to keep the servers responsive while running.
  • Vibrate – for optional haptic feedback.
  • Request ignore battery optimizations – optional, so Android does not stop your servers; you decide whether to allow it.

The app does not access your contacts, camera, microphone, location, photos or other personal data. Files are only read when you explicitly pick them with the Android file picker (for example when importing project files).

6. Third-party software

The app bundles open-source software that runs entirely on your device: PHP, MariaDB, phpMyAdmin and Cloudflare's cloudflared client. These components are used under their respective open-source licenses.

7. Children

The app is a developer tool and is not directed to children under 13. We do not knowingly collect data from children.

8. Security

Data is kept in the app's sandboxed storage. If you make your server reachable from other devices or the internet, please set a strong MySQL root password and do not store sensitive data in a publicly reachable site.

9. Changes to this policy

If this policy changes, the updated version will be published at this address with a new effective date.

10. Contact
